# STT 보이스피싱 점수 산출 방식 설명

## 한 줄 요약

피싱 점수는 **단순히 "위험 키워드가 몇 개냐"가 아니라**, ① 키워드 가중치 합, ② 카테고리 다양성 보너스, ③ 금액 패턴 보너스, ④ 구문/시너지 보너스를 합산해 **0~100%로 산출**하는 점수다. 그래서 위험 신호가 누적될수록 점수가 단계적으로 올라가며, 실제 데모(양정윤 사칭)에서는 "100만 원" → "계좌"가 순서대로 등장하며 **10% → 35%**로 점수가 상승한다.

## 발표용 짧은 설명

> 저희 STT 피싱 점수는 키워드 하나당 1점을 매기는 단순 카운트가 아닙니다. 각 키워드에 위험도 가중치를 부여하고, 서로 다른 범주(사칭·금융행위·개인정보·위협 등)의 신호가 함께 나타날수록 보너스를 줍니다. 여기에 "100만 원" 같은 금액 표현을 자동 감지해 추가 점수를 더합니다. 즉, **여러 위험 신호가 누적되는 정도를 0~100%로 정량화**한 점수입니다. 데모에서 보신 10%에서 35%로의 상승은, "금액 언급"이라는 약한 신호 위에 "계좌"라는 금융행위 키워드가 더해지며 위험도가 실시간으로 누적되는 과정을 보여줍니다.

## 점수 공식

피싱 점수는 두 단계(Tier)의 탐지 결과를 결합해 산출한다.

```text
최종 점수 = max(키워드 점수, 구문 점수) + 금액 보너스 + 시너지 보너스
            (최종값은 0.0 ~ 1.0 사이로 클리핑)
```

각 항목의 의미는 다음과 같다.

| 항목 | 의미 | 값 |
|---|---|---|
| **키워드 점수** | 매칭된 키워드들의 가중치 합 + 카테고리 다양성 보너스 | 가변 |
| **구문 점수** | 문맥상 피싱 구문 패턴(bigram/trigram) 매칭 점수 | 가변 |
| **금액 보너스** | "100만 원", "1억" 등 금액 표현 감지 시 가산 | +0.1 |
| **시너지 보너스** | 키워드·구문 신호가 **둘 다** 강할 때 가산 | +0.1 |

그리고 **키워드 점수**는 다시 다음과 같이 계산된다.

```text
키워드 점수 = Σ(매칭된 키워드 가중치) + (서로 다른 카테고리 수 × 0.05)
```

- **키워드 가중치**: 키워드마다 위험도를 다르게 부여한다. 예) "금융감독원" 0.5, "계좌이체" 0.4, "계좌" 0.2.
- **카테고리 다양성 보너스**: 사칭·긴급·금융행위·개인정보·위협 중 서로 다른 범주가 동시에 나타나면 범주 1종당 0.05를 더한다. (사칭 + 금융행위처럼 조합될수록 실제 피싱일 확률이 높기 때문)

## 등급 기준

최종 점수에 따라 4단계 위협 등급으로 표시된다.

| 점수 | 등급 | 의미 |
|---|---|---|
| **≥ 50%** | HIGH | 피싱 가능성 높음 |
| **≥ 25%** | MEDIUM | 정황상 의심 |
| **≥ 10%** | LOW | 약한 의심 신호 |
| **< 10%** | NONE | 정상 |

## 실제 데모 예시 — 양정윤 사칭(demo_11)

합성 음성 전사문:

> "안녕하세요. 김명석 교수님, 양정윤입니다. 이번 프랙티컴 진행하다 보니 지원금이 많이 부족하더라고요. 지도 교수님 재량으로 **100만 원** 정도만 저희 팀 **계좌**에 지원해 주실 수 있나요?"

전사가 진행되며 점수가 단계적으로 상승한다.

| 발화 시점 | 발동된 요소 | 계산 | 점수 | 등급 |
|---|---|---|---|---|
| **"100만 원"** | 금액 패턴 보너스만 | `0 + 0.1` | **10%** | LOW |
| **"계좌"** | 계좌 키워드(0.2) + 카테고리 보너스(0.05) + 금액 보너스(0.1) | `(0.2 + 0.05) + 0.1` | **35%** | MEDIUM |

> 키워드는 "계좌" **하나뿐**이지만, 점수에 들어가는 항목은 **세 가지**다 —
> ① 키워드 가중치 0.2, ② 카테고리 다양성 보너스 0.05, ③ 금액 패턴 보너스 0.1.
> 그래서 "금액 언급"이라는 약한 신호(10%)가 먼저 켜지고, 뒤이어 "계좌"라는 금융행위 키워드가 더해지며 35%로 누적된다.

## 발표 한 장 요약

```text
피싱 점수 = 위험 신호의 "누적량"을 0~100%로 정량화한 값

  ┌─ 키워드 가중치 합      (계좌 0.2)
  ├─ 카테고리 다양성 보너스 (금융행위 1종 → 0.05)
  ├─ 금액 패턴 보너스       (100만 원 → 0.10)
  └─ 구문/시너지 보너스     (문맥 패턴, 본 예시는 0)

  [양정윤 사칭 데모]
    "100만 원" 등장 → 10% (LOW)   ── 약한 신호 점등
        ↓
    "계좌" 등장     → 35% (MEDIUM) ── 금융행위 키워드 누적

  → 키워드 1개라도, 금액·범주·문맥 신호가 합쳐져 위험도가 단계적으로 상승
```
