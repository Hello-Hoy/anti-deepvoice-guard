# GPT-SoVITS 모델 설명

## 한 줄 요약

**GPT-SoVITS**는 텍스트를 음성으로 변환하는 TTS(Text-to-Speech) 모델이면서, 짧은 참조 음성의 음색과 말투를 반영할 수 있는 **few-shot voice cloning** 계열 음성 합성 모델이다. 핵심 구조는 텍스트를 먼저 말소리의 중간 표현인 **semantic token**으로 바꾸는 GPT 계열 모델과, 그 semantic token을 실제 음성 파형으로 복원하는 **SoVITS** 계열 모델의 결합이다.

## 교수님께 설명할 짧은 답변

> GPT-SoVITS는 텍스트를 바로 wav로 만드는 단일 모델이라기보다, 두 단계로 음성을 합성하는 모델입니다. 먼저 GPT 계열 text-to-semantic 모델이 입력 문장을 말소리의 중간 표현인 semantic token으로 예측합니다. 그 다음 SoVITS 계열 음성 생성 모델이 semantic token과 참조 음성의 특징을 이용해 실제 음성 파형을 만듭니다.
>
> 이 모델은 약 5초 정도의 짧은 참조 음성만으로도 해당 화자의 음색을 반영하는 zero-shot TTS가 가능하고, 추가 음성 데이터로 파인튜닝하면 특정 화자의 유사도와 발화 안정성을 더 높일 수 있습니다. 따라서 딥보이스 탐지 실험에서 실제 보이스피싱 상황에 가까운 AI 합성 음성을 만들 수 있는 모델로 사용하기 적합합니다.

## GPT-SoVITS가 무엇인가

GPT-SoVITS는 소량의 음성 데이터만으로 특정 화자의 목소리 특성을 반영해 새로운 문장을 읽게 하는 음성 합성 시스템이다. 공식 문서 기준 주요 기능은 다음과 같다.

- **Zero-shot TTS**: 짧은 참조 음성을 입력하면 별도 학습 없이도 해당 음색을 참고해 텍스트를 음성으로 합성한다.
- **Few-shot TTS**: 약간의 음성 데이터를 추가로 학습하면 화자 유사도와 자연스러움을 높일 수 있다.
- **Voice cloning**: 참조 음성의 음색, 톤, 말투를 반영해 새 문장을 말하는 것처럼 합성한다.
- **다국어 지원**: 한국어, 영어, 일본어, 중국어, 광둥어 등 여러 언어 합성을 지원한다.
- **데이터 준비 도구**: 음성 분리, 자동 세그먼트 분할, 텍스트 라벨링 등 학습 데이터 준비 도구를 포함한다.

여기서 중요한 점은 GPT-SoVITS가 단순히 “문장을 기계음으로 읽는 TTS”가 아니라, **참조 음성의 화자 특성을 조건으로 받아 새 음성을 생성하는 모델**이라는 점이다.

## 전체 모델 구조

GPT-SoVITS는 크게 네 단계로 이해할 수 있다.

```text
입력 텍스트 + 참조 음성
  -> 텍스트 전처리 및 발음 단위 변환
  -> GPT text-to-semantic 모델이 semantic token 예측
  -> SoVITS 모델이 semantic token과 참조 음성 특징을 결합
  -> 실제 음성 wav 출력
```

각 단계의 역할은 다음과 같다.

### 1. 텍스트 전처리

입력 문장은 모델에 바로 들어가지 않는다. 먼저 문장 분할, 특수기호 정리, 언어 판별, 발음 단위 변환을 거친다. 긴 문장은 구두점이나 길이 기준으로 나뉘어 처리된다.

이 단계의 목적은 사람이 쓰는 자연어 문장을 모델이 처리할 수 있는 **phoneme ID**와 정규화된 텍스트 표현으로 바꾸는 것이다. 발음 단위 정보는 이후 semantic token 예측과 음성 복원 과정에서 사용된다.

### 2. Semantic token

GPT-SoVITS에서 중요한 중간 표현은 **semantic token**이다. semantic token은 원본 음성 파형 자체가 아니라, 말의 내용, 리듬, 발화 흐름을 압축한 음성 표현에 가깝다.

사람이 이해하기 쉽게 말하면 다음과 같다.

- 텍스트: “무엇을 말할지”
- semantic token: “그 문장을 어떤 말소리 흐름으로 말할지”
- 최종 wav: “실제로 들리는 음성”

이 중간 표현을 사용하면 텍스트 처리와 음성 파형 생성을 분리할 수 있다. 그래서 GPT 계열 모델은 semantic token 예측에 집중하고, SoVITS 계열 모델은 이를 자연스러운 음성으로 복원하는 데 집중한다.

### 3. GPT text-to-semantic 모델

GPT 부분은 입력 텍스트와 발음 단위 정보를 바탕으로 semantic token 시퀀스를 예측한다. 일반적인 대규모 언어 모델이 다음 단어를 예측하듯이, GPT-SoVITS의 GPT 모델은 다음 semantic token을 순차적으로 예측한다.

이 단계에서 `top_k`, `top_p`, `temperature` 같은 샘플링 파라미터가 사용될 수 있다.

- `top_k`: 후보 token 수를 제한해 발화를 더 안정적으로 만든다.
- `top_p`: 누적 확률 기준으로 후보 token 범위를 조절한다.
- `temperature`: 낮을수록 안정적이고, 높을수록 다양하지만 흔들릴 수 있다.

즉 GPT 부분은 최종 음성을 직접 만들기보다, SoVITS가 사용할 **말소리 설계도**를 만드는 역할에 가깝다.

### 4. SoVITS 음성 생성 모델

SoVITS 부분은 GPT가 예측한 semantic token을 실제 음성으로 바꾸는 역할을 한다. 이때 목표 문장의 발음 단위 정보와 참조 음성의 acoustic feature를 함께 사용한다.

SoVITS는 VITS 계열 음성 합성 구조를 기반으로 하며, semantic token을 음성의 acoustic representation으로 변환한 뒤 최종 파형을 생성한다. 쉽게 말하면 GPT가 만든 “말소리 흐름”을 실제로 들리는 목소리로 렌더링하는 단계다.

## 참조 음성(prompt)의 역할

GPT-SoVITS에서 참조 음성은 매우 중요하다. 참조 음성은 모델에 “이런 음색과 톤으로 말해 달라”는 조건을 제공한다.

참조 음성은 보통 몇 초 정도의 짧은 음성으로 충분하다. 모델은 이 음성에서 다음과 같은 정보를 참고한다.

- 화자의 음색
- 발화 톤
- 말의 질감
- 억양과 리듬의 경향
- 녹음 환경의 일부 특성

따라서 같은 텍스트라도 어떤 참조 음성을 넣느냐에 따라 합성 결과의 인상이 달라질 수 있다. 이 점이 GPT-SoVITS가 일반 TTS보다 voice cloning에 더 적합한 이유다.

## Zero-shot과 Few-shot의 차이

GPT-SoVITS는 zero-shot과 few-shot 두 방식으로 설명할 수 있다.

| 구분 | 의미 | 장점 | 한계 |
|---|---|---|---|
| Zero-shot | 짧은 참조 음성만으로 바로 합성 | 빠르고 데이터가 적게 필요함 | 화자 유사도와 안정성이 제한될 수 있음 |
| Few-shot | 소량의 화자 데이터로 추가 학습 후 합성 | 화자 유사도와 자연스러움 향상 | 데이터 준비와 학습 시간이 필요함 |

딥보이스 탐지 실험에서는 단순 기계음보다 특정 화자처럼 들리는 합성 음성이 더 현실적인 테스트 조건을 만든다. 그래서 GPT-SoVITS처럼 zero-shot/few-shot voice cloning이 가능한 모델이 실험용 AI 음성 생성에 자주 사용된다.

## 한국어 합성에서의 특징

GPT-SoVITS는 한국어 합성을 지원하지만, 한국어는 영어처럼 띄어쓰기와 발음이 단순히 일대일 대응하지 않고, 조사/어미/받침/연음 등 발음 변화가 많다. 따라서 한국어 합성에서는 텍스트 정규화와 발음 단위 변환이 중요하다.

또한 긴 문장을 한 번에 넣으면 발음이 흔들리거나 후반부가 부자연스러워질 수 있다. 그래서 실제 사용에서는 문장을 적절히 나누고, 고유명사나 영어 약어는 한글 발음으로 풀어 쓰는 방식이 도움이 된다.

## 모델의 장점

- 적은 음성 데이터로도 화자 특성을 반영할 수 있다.
- 참조 음성 기반 합성이 가능해 특정 화자 스타일을 재현하기 쉽다.
- 텍스트 입력만 바꾸면 다양한 문장을 같은 음색으로 생성할 수 있다.
- GPT와 SoVITS 역할이 분리되어 있어 텍스트 흐름 예측과 음성 복원이 비교적 명확하게 나뉜다.
- 한국어를 포함한 다국어 합성을 지원한다.

## 모델의 한계

- 참조 음성 품질이 낮으면 합성 품질도 떨어진다.
- 학습 데이터의 말투가 방송체라면 합성 결과도 방송체에 가까워질 수 있다.
- 긴 문장은 반복, 누락, 발음 흔들림이 생길 수 있다.
- 특정 화자와 완전히 동일한 목소리를 보장하는 모델은 아니다.
- 생성 결과의 자연스러움은 모델 구조뿐 아니라 데이터 품질, 참조 음성, 샘플링 설정에 크게 의존한다.

## 딥보이스 탐지 관점에서의 의미

GPT-SoVITS 같은 모델은 짧은 참조 음성만으로도 특정 화자처럼 들리는 음성을 만들 수 있기 때문에, 보이스피싱과 같은 음성 기반 사칭 공격의 현실성을 높인다. 탐지 시스템 입장에서는 단순 TTS 음성뿐 아니라, 이런 voice cloning 계열 합성 음성까지 판별할 수 있어야 한다.

따라서 GPT-SoVITS는 탐지 모델을 설명할 때 “공격자가 사용할 수 있는 고품질 합성 음성 생성 모델의 예시”로 설명하기 좋다. 핵심은 이 모델을 악용하는 것이 아니라, 이런 기술이 존재하기 때문에 딥보이스 탐지 기술이 필요하다는 점을 보여주는 것이다.

## 발표용 핵심 문장

> GPT-SoVITS는 텍스트를 바로 음성으로 바꾸는 단순 TTS가 아니라, GPT 모델이 먼저 말소리의 semantic token을 예측하고, SoVITS 모델이 이를 참조 음성의 화자 특성과 결합해 실제 음성 파형으로 복원하는 구조입니다. 짧은 참조 음성만으로도 특정 화자 스타일을 반영할 수 있고, 추가 데이터로 파인튜닝하면 더 자연스러운 voice cloning이 가능합니다. 그래서 딥보이스 탐지 실험에서 실제 사칭 음성에 가까운 AI 음성을 만들 수 있는 대표적인 모델로 볼 수 있습니다.
